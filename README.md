Sobre o projeto.
O SkillBridge é uma plataforma que conecta estudantes de escolas técnicas a
micro e pequenas empresas locais que buscam profissionais para estágios,
serviços técnicos e microprojetos.
O sistema utiliza inteligência artificial e análise de dados para realizar o “match”
entre habilidades, localização e disponibilidade, gerando empregabilidade prática
e imediata.
A startup surge para atender à lacuna entre formação técnica e mercado de trabalho
real, promovendo trabalho decente, educação de qualidade e redução das
desigualdades (ODS 4, 8 e 10).
O modelo de negócios é baseado em assinatura freemium para escolas e
empresas, com taxa de intermediação por contrato fechado.
O produto é uma plataforma web e mobile, com backend em Java (API REST),
frontend em React, banco Oracle, e IA em Python/Flask, totalmente integrada.
A SkillBridge inova ao usar tecnologia de IA e reputação gamificada para conectar
talentos locais a oportunidades reais, de forma simples e justa.
